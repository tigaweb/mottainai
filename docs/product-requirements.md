# Product Requirements

## Vision

「mottainai」は、家庭の食材在庫を可視化し、食品ロスの削減を促すモバイルアプリ。
"何がどのくらい残っているか"を直感的に把握できることで、買いすぎ・使い忘れを防ぎ、食材を使い切る行動を自然に促す。

## Target User

家に何がどのくらい残っているか把握できず、つい同じ食材を買いすぎたり使い切れず捨ててしまう人。

## User Stories

### US-1: 買い物前に在庫を確認する

> 買い物に行く前にアプリを開いて、今ある食材の残量を確認し、何を買うべきか判断したい。

**受け入れ条件:**
- 在庫一覧画面で全食材とその残量（パーセンテージバー）が一目で分かる
- カテゴリごとにグルーピングされている

### US-2: 使った / 買い足した後に残量を更新する

> 料理で食材を使ったり、買い物から帰ったときに、残量をサッと更新したい。

**受け入れ条件:**
- スライダー操作で残量を直感的に変更できる
- 「使い切り」「廃棄」をワンタップで記録できる
- 使い切り時にポジティブフィードバック（ロス削減への貢献を実感）

### US-3: 食品ロス削減の実績を確認する

> 自分がどれだけ食材を無駄にせず使い切れたかを振り返り、モチベーションにつなげたい。

**受け入れ条件:**
- 使い切り回数・廃棄回数が集計されている
- 一定期間の実績をサマリーとして表示

## Functional Requirements

### F-1: 食材在庫一覧

- 登録済み食材をカード形式で一覧表示
- 各カードに食材名・カテゴリアイコン・残量バー（0〜100%）を表示
- カテゴリでのフィルタリング

### F-2: 食材追加

- 食材名（必須）・カテゴリ（必須）を入力して登録
- 初期残量は 100%
- カテゴリ: 野菜、果物、肉、魚、乳製品、調味料、その他

### F-3: 食材詳細 / 残量更新

- スライダーで残量を 0〜100% の範囲で変更
- 「使い切り」ボタン: 残量を 0% にし、consumed として記録
- 「廃棄」ボタン: 残量を 0% にし、wasted として記録
- 使い切り時にポジティブフィードバックを表示

### F-4: サマリー

- 使い切り回数（consumed count）
- 廃棄回数（wasted count）
- 使い切り率（consumed / (consumed + wasted)）
- 現在の在庫アイテム数

## Non-functional Requirements

### NF-1: オフライン完結

- ネットワーク接続不要で全機能が動作する
- データはすべて端末内（SQLite）に保存

### NF-2: パフォーマンス

- 画面遷移は 300ms 以内
- 食材 100 件以上でもスムーズにスクロール

### NF-3: 対応プラットフォーム

- iOS / Android（Expo managed workflow）

### NF-4: デモ対応

- EcoHack 提出のデモ動画で以下の導線を実演できること:
  1. アプリを開く → 在庫一覧が並んでいる
  2. 「にんじん」の残量をスライダーで下げる（使った）
  3. 「牛乳」を使い切り → ポジティブフィードバック表示
  4. 「卵」を新しく買い足し → バーが上がる
  5. サマリー画面 → 「今週の使い切り 3件」など実績表示

## Out of Scope (MVP)

- ユーザー認証 / アカウント管理
- クラウド同期 / マルチデバイス
- レシピ提案
- 賞味期限管理
- バーコードスキャン
- プッシュ通知
